# Data Outputs
### How to interpret the data outputs

## Mission Data
### What is the Mission?
The primary mission of the FKW detector parse audio data collected by an underwater seaglider and detect instances of False Killer Whale whistles in near real-time. These detections are used to give NOAA operativese a real-time understanding of False Killer Whale localizations in the pacific. 

### Data_Products
All data generated by the FKW_detector goes to:

```bash
/FKW_detector/data_products/
```
*Please note. this folder is created as needed, in otherwords, it will not exist if no data has been analyzed.* 

### packets (Mission Data)
The FKW_detector creates one 'packet' per analyziation cycle. Packets are named by the first-last .dat file analyzed, ex: ```240930_000003-241001_000449_packetizeds.csv```. Each packet contains a paired list of time and number of detections for each 30 seconds time window in the analyziation cycle that contains at least one detection. This is a minimalistic summary of the most recent deployment cycle and is designed for easy transmission through the glider's radio system. 

```csv
start_time,detections
2024-09-30 00:00:03,8
2024-09-30 00:00:33,2
2024-09-30 00:01:05,3
```

## Developer Data
*The following data is mainly developers who are trying to fix, improve, or troubleshoot the FKW_detector*

### inference_outputs
Again, one inference file per analyzation cycle with the same naming schema from the packets. There is ONE ENTRY PER EACH DETECTION. That means there can be, and probably is, multiple entries per file. Remember that each file (ex: 'WISPR_240930_000003-0001.jpg') represents 30 seconds of audio data. 

Each entry contains a file name, time (add 30s for files that end with 0011), confidence, bounding box, and total bounding boxes for that image. These things are usefull for evaluating model accuracy and understanding 'what the model was thinking'. 

### spectro_outputs
The FKW_detector uses YOLO to analyze visual data, meanwhile, the glider records audio data... You can already see the descrepancy. Audio comes out of the WISPR in one minute chunks, FKW_detector processes the audio and turns each one minute chunk into two images. Each image has ten spectrogram strips that each represent three seconds of audio data in the 4kHz-9kHz range; one image therefor represents thirty seconds of audio data. The images in spectro_outputs are what the YOLO model analyzes, FKW whales whistles generally look like horizantal black streaks in these spectrograms. A good whistle, or collection of whistles, will be fairly obvious. 

### wave_outputs
The WISPR outputs .dat files but the audio to spectro script can only interpret .wav files, hence, transforming .dat files into .wav files is an intermediary step. 

Remember, each wave file should be about one minute while each sprectrogram image should represent about 30 seconds (two image files per one wav file).
